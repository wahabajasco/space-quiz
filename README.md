# Space Explorer Quiz

A colorful, responsive space-exploration quiz with 10 multiple-choice questions, animated answer feedback, a live score, and a final results screen. The app is a single self-contained HTML file with no server, build step, or runtime dependencies.

## Run locally

Open `index.html` in a modern web browser. No installation or local server is required.

## Deploy

The GitHub Actions workflow in `.github/workflows/pages.yml` publishes the site to GitHub Pages whenever changes are pushed to `main`. Pull requests run a basic check that the site entry point exists.
