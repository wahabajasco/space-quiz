# Project rules

- Keep the quiz self-contained in `index.html`; do not add a server, build step, or runtime dependency.
- Preserve the responsive, narrow-column layout, both color schemes, and reduced-motion support.
- Keep interactions accessible: use semantic controls, clear keyboard focus, and announce quiz feedback and results.
- When changing quiz behavior, verify keyboard navigation, scoring, answer feedback, results, and restart in the browser.
- Keep edits focused and use the existing HTML, CSS, and JavaScript patterns.
